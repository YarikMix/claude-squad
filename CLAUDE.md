# Работа с этим репозиторием

Форк [smtg-ai/claude-squad](https://github.com/smtg-ai/claude-squad), который ведётся под задачи команды.

## Язык

**Заголовки и описания pull request'ов, а также changelog релизов — на русском.** Их читают участники команды, а не апстрим.

Префикс заголовка (`fix:`, `feat:`, `docs:`, `refactor:`) остаётся английским: он машиночитаемый и попадает в фильтры changelog'а. По-русски пишется всё, что после него.

```
fix: приводить сессию терминала к размеру панели при показе, а не только при создании
```

На английском остаётся то, что живёт в коде и в истории:

- сообщения коммитов;
- комментарии и идентификаторы в коде;
- `README.md` и прочая документация репозитория.

Причина разделения простая: коммиты и код могут уехать в апстрим отдельным pull request'ом, а описание PR и заметки к релизу — нет, они принадлежат форку.

Не переводятся никогда: названия клавиш и команд (`R`, `Ctrl+X`, `p push branch`), ключи конфигурации (`restart_args`, `default_program`), пути, имена функций и цитаты из интерфейса. Пользователь ищет их глазами по экрану — перевод сделает текст бесполезным.

## Changelog релиза

GoReleaser собирает список коммитов автоматически, и этот список читать невозможно: в нём хеши, служебные коммиты вроде `Bump version`, и каждая правка задвоена мерж-коммитом. Заметки к релизу пишутся руками поверх черновика.

Полезная заметка отвечает не «что изменилось в коде», а «что теперь иначе для того, кто этим пользуется»: что было сломано или неудобно до, что стало, и какой ключ конфигурации это настраивает.

Релиз собирается как черновик, так что текст можно заменить до публикации:

```bash
gh release edit vX.Y.Z --repo YarikMix/claude-squad --notes-file notes.md
```

Правка черновика через API сбрасывает привязку к тегу — после неё проверьте `tag_name` и при необходимости верните его тем же вызовом.
